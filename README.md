# QA Automation Studies

This repository contains my hands-on studies and practice projects in QA Automation,
covering test automation tools, frameworks, and best practices as I transition into
a QA Automation role.

## Structure

Each folder represents a course or study track:

- playwright-pytest/ — Web test automation with Playwright, Python, and Pytest
- selenium-webdriver-python/ — Web test automation with Selenium WebDriver and Python
- practical-sql-python/ — SQL practice with Python (SQLite, MySQL, PostgreSQL + FastAPI)
- Api_test/ — API test automation framework with Pytest (client/helper layers, fixtures,
  parametrized tests, SQL-backed assertions, HTML reports, and a CI/CD pipeline running
  on GitHub Actions)

## Background

QA Engineer with hands-on experience in functional, integration, and regression
testing of telecom hardware/software (GPON OLTs, FGWs, routers, switches).
Currently expanding into test automation, aiming for a fully remote QA Automation role.

## Tech Stack

Python, Selenium WebDriver, Playwright, Pytest, SQL, FastAPI, Git, GitHub Actions (CI/CD)

## Notes

This is a living repository — updated as I progress through courses and build
independent practice projects. The Api_test framework runs automatically on every
pull request via a GitHub Actions pipeline, validating API behavior end-to-end
and generating an HTML test report as a build artifact.
